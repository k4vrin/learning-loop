# Refresh policy

- Prefer official documentation, specifications, standards bodies, maintainers,
  and original research.
- Verify the page currently supports the claim and record the verification date.
- Distinguish a changed fact from a better explanation of an unchanged fact.
- Preserve stable card IDs only when the tested capability remains the same.
- If a primary source conflicts with a secondary source, use the primary source
  and record the discrepancy when it affects learning.
- Summarize copyrighted sources; do not copy substantial passages.
- Keep unresolved uncertainty visible rather than forcing a definitive answer.
