# Progress review rubric

Review a meaningful recent window rather than lifetime totals.

1. **Adherence:** On how many available days did the learner attempt at least one
   planned retrieval or performance?
2. **Retention:** Which cards were answered `Good` or `Easy` unaided on a later
   date, and which repeatedly returned `Again` or `Hard`?
3. **Transfer:** Can the learner apply the capability in a changed example,
   debugging scenario, explanation, or mixed problem?
4. **Calibration:** Compare confidence with correctness and assistance.
5. **Coverage:** Which required capabilities have representative evidence, and
   which remain untested?
6. **Readiness:** Apply the track's own realistic assessment and threshold.

Prefer one or two high-leverage changes to a wholesale rescheduling of the track.
